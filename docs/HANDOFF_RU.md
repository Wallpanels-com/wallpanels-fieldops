# Краткая инструкция пользователю

## Запуск красивого демо локально (перед работой с Codex)

```bash
npm run preview
```

Откройте `http://localhost:3000/?preview=1`. Дизайн, карточки и часть интерфейсных действий работают с демоданными, без Supabase и Telegram. В этом режиме данные не сохраняются.

## Для реального запуска

1. Использовать только текущие значения из утверждённого локального документа и не выводить их в чат, логи или Git. При любом раскрытии немедленно перевыпустить значение.
2. Дать Codex доступ **только к корпоративным** GitHub/Supabase/Railway.
3. Codex проверяет корпоративный scope, выполняет SQL-миграцию, деплоит Railway, настраивает ключи в Railway Variables и меню Telegram-бота.
4. Получить собственный числовой Telegram ID через бота `/start` (либо безопасный Telegram ID бот) и выставить `BOOTSTRAP_ADMIN_TELEGRAM_ID`.
5. Открыть Mini App в Telegram → Profile → выбирать Installer / Project Manager. Создать тестовый проект и пройти все этапы.

## Исходный документ `fieldops`

Документ `fieldops`, расположенный на Desktop, используется только как локальный источник текущих значений и для проверки имени проекта/URL. Секреты из него нельзя печатать, коммитить или переносить в исходный код; они задаются только как переменные окружения сервиса.
